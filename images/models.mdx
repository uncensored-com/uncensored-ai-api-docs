# Image Models <Badge color="green" shape="pill">Live</Badge>

Default model: `model-dev`. The API can default `model` when omitted, but production integrations should send it explicitly so the selected provider is clear.

`common` means `image_width`, `image_height`, `callback_url`, `resolution`, `quality`, `additional_settings`, and `enable_fallback`. Model-specific knobs such as `seed`, `negative_prompt`, `aspect_ratio`, `num_inference_steps`, `guidance_scale`, and `output_format` are passed in `additional_settings` unless they are documented as top-level convenience params.
