# Images

Two endpoints share the same growing model catalog: generate images from a text prompt, or edit existing images with a text instruction plus reference image(s).

## Endpoints

```text
POST /v1/images/generations
POST /v1/images/studio/edit
```

## Sync and async modes

`POST /v1/images/generations` returns synchronously by default. Include a `callback_url` to run the job asynchronously — the API responds with `202`, a `job_id`, and a `status_url` you can poll.

`POST /v1/images/studio/edit` is always async — it returns immediately with a `job_id` you can poll or pair with a `callback_url` for webhook delivery.
