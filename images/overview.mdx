## Endpoint

```text
POST /v1/images/generations
```

## Sync and async modes

Include a `callback_url` to run the job asynchronously — the API responds with `202`, a `job_id`, and a `status_url` you can poll. Omit `callback_url` and supported models return the image synchronously.
