# Video Generation <Badge color="green" shape="pill">Live</Badge>

```text
POST /v1/videos/generations
```

Generate a video from a text prompt, reference image, or source video. The endpoint queues work for async delivery via `callback_url`.

## Request body

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `model` | string | Yes | Video model ID. See the model table below. |
| `prompt` | string | Conditional | Text prompt or editing instruction. Required for text-to-video and supported on transform models that list it. |
| `callback_url` | string | No | Webhook URL for async delivery. |
| `seconds` | number | No | Requested clip duration. Supported values vary by model. |
| `resolution` | string | No | Model-specific output resolution such as `480p`, `540p`, `580p`, `720p`, `1080p`, or a range where listed. |
| `aspect_ratio` | string | No | Output aspect ratio for models that support explicit aspect control. |
| `image_url` | string | Conditional | Required for image-to-video models unless the row says the image is optional. |
| `end_image_url` | string | No | Optional ending frame for models that support start/end image guidance. |
| `video_url` | string | Conditional | Required for video-to-video, video edit, and video extend models. |
| `additional_settings` | object | No | Model-specific provider settings such as `seed`, `negative_prompt`, and `generate_audio`. |
| `enable_fallback` | boolean | No | Enable automatic model fallback. Default: `true`. |

## Models

`common` means `callback_url`, `additional_settings`, and `enable_fallback`. Model-specific provider knobs such as `seed`, `negative_prompt`, and `generate_audio` are passed in `additional_settings`. `generate_audio` is only supported on audio-capable models (those that list it below); setting `generate_audio: true` adds an audio track and roughly doubles the per-second cost. ## Example request

```bash
curl --request POST "https://api.uncensored.com/api/v1/videos/generations" \
  --header "x-api-key: YOUR_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "prompt": "A cinematic drone shot over a misty mountain range at sunrise",
    "model": "t2v-turbo",
    "seconds": 5,
    "resolution": "720p",
    "callback_url": "https://your-server.com/webhook"
  }'
```

## Example response

```json
{
  "id": "vid_abc123",
  "status": "processing",
  "model": "t2v-turbo",
  "created_at": "2025-06-01T12:00:00Z"
}
```

When processing completes, the result is delivered to your `callback_url`.

## Audio on supported models

Audio-capable models (those that list `generate_audio` in the table above, such as `seedance-2.0-spicy`) accept `generate_audio` inside `additional_settings`. It defaults to off; setting it to `true` adds an audio track and roughly doubles the per-second cost.

```bash
curl --request POST "https://api.uncensored.com/api/v1/videos/generations" \
  --header "x-api-key: YOUR_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "prompt": "A neon city street at night with ambient sound",
    "model": "seedance-2.0-spicy",
    "image_url": "https://your-server.com/start.jpg",
    "seconds": 5,
    "resolution": "480p",
    "additional_settings": { "generate_audio": true },
    "callback_url": "https://your-server.com/webhook"
  }'
```
