<Badge color="green" shape="pill">Live</Badge>

The full catalog of chat models, loaded live from the API and listed newest first. Use the `Model ID` exactly as shown when sending [chat completion](/chat/completions) requests.

Pricing is per million tokens. Input and output rates are shown on every model, and where a model supports prompt caching the cache read and cache write rates are shown underneath. A model that reads `Pricing not published` has no price in the catalog yet, so check it before you build against it: the rate is not zero.

<Note>
  This list is fetched from `GET /v1/models` in real time, so it always reflects what's currently available. The same endpoint lists image, image-edit and video models with `?type=image|inpaint|video|all` — see [Listing models programmatically](/models#listing-models-programmatically).
</Note>
